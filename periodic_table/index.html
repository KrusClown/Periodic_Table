How to read a tile

6C12.011
  • 6Atomic number. How many protons live in the nucleus. It is the element's ID card.
  • CSymbol. One or two letters. Some come from Latin: Fe is ferrum, iron.
  • 12.011Atomic mass. How heavy one atom is, in atomic mass units (u). Numbers in brackets are lab-made atoms that never sit still.
  • RowPeriod. Same row, same number of electron shells.
  • ColumnGroup. Same column, similar personality.
